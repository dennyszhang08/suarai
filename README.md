# Suarai: One-stop audio/video processing solution

## Features

- Audio Transcription
- Speech Analysis
- Host/Record Synchronous Audio/Video Call
- Whiteboard support for Synchronous Audio/Video Call
- English Communication Assessment (Fluency, Coherence, and Grammar)

## Technical Specifications

### Backend

- Python 3.12
- FastAPI
- Redis
- Celery
- WhisperX

### Frontend

- TypeScript
- React
- Tailwind
- Canvas-based library (vanilla html5, Pixijs, Threejs, etc.)

### Tools/Others

- `uv` for backend development
